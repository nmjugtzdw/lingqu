# 灵渠 Lingqu

灵渠是给实施与运维人员用的数据库同步与迁移工具。它把「连接 → 结构迁移 → 全量装载 → 增量同步 → 校验修复 → 运行审计」整理成一条可复现的任务流程，支持完全离线的内网部署。

**当前正式版本：v1.0.2（2026 年 11 月）**

## 这版能感受到什么

- **第一次打开不用猜该点哪里**：新增首次进入引导，在建连接、填表单、建任务、看任务列表的页面上，按顺序标出该点哪里、每一步做什么
- **引导只做说明，不替你操作**：不会替你填账号密码、不会保存连接、更不会启动同步任务；点「跳过引导」随时自己上手
- **随时能重看**：看过一次后，侧栏底部点「新手引导」就能重新打开
- **沿用 v1.0.1 的改进**：项目多了搜索和状态筛选、首页有「首次同步：三步开始」提示、看板文案更清楚
- **沿用 v1.0.0 的全部能力**：打开就是中文、手机浏览器可看、建任务一步一页随时存草稿、跑完能导出报告、Windows 免安装包解压双击就能用

## 能做什么

- **连得上各类数据库**：内置 MySQL、MariaDB、PostgreSQL、SQL Server、H2；连接 Oracle、DB2、达梦、人大金仓、OceanBase 等数据库时，在「驱动管理」里上传一次对应厂商提供的驱动即可，升级程序不用重传
- **结构和数据一起搬**：表结构、索引、全量数据一次完成
- **增量同步**：定时增量，或基于数据库日志的秒级实时同步
- **跑得久也稳**：断点续传、并行分片、任务调度、失败重试、重启后接着跑
- **数据对得上**：抽查、差异诊断、表级重跑、切换追赶、运行审计
- **实施工具齐**：ETL、字段映射、批量规划、驱动管理
- **本地化部署**：配置与记录都存在本机，凭据加密、账号权限、日志轮转，不依赖外网

日常使用只需要首页、新建任务、同步任务、连接和设置；ETL、校验、日志等专业能力收在「高级能力」里。

## 下载与安装

**从 v1.0.2 起只提供一个版本**，下面两个文件功能完全一样，按电脑情况任选其一：

| 文件 | 适合谁 |
|---|---|
| `lingqu-1.0.2-lite-windows-x64.zip` | Windows 电脑，**自带 Java**，解压后双击 `start.bat` 即可（推荐） |
| `lingqu-1.0.2-lite.jar` | 已经装了 Java 17 的 Windows / Linux 电脑 |

安装步骤：

1. 到 [Releases](https://github.com/nmjugtzdw/lingqu/releases) 或[官网下载区](https://lingqu.zzzmxxkj.com/#files)下载 **v1.0.2**
2. 免安装包解压后双击 `start.bat`；浏览器打开 <http://127.0.0.1:27402>
3. 首次启动的管理员密码在 `data/initial-password.txt`，登录后请立即修改

两个文件的 SHA-256 校验值见同页的 `SHA256SUMS-v1.0.2.txt`；官网提供的是同样的两个文件。

软件内置 MySQL、MariaDB、PostgreSQL、SQL Server、H2 的驱动。需要连接 Oracle、DB2、达梦、人大金仓、OceanBase 等数据库时，打开软件里的「驱动管理」，上传一次对应厂商提供的驱动即可；上传后会保留，升级程序不用重新上传。如果确实需要预置这些驱动的安装包，请通过下方「获取帮助」联系我们。

### 从旧版本升级

1. 先停止旧程序，**完整备份 `data` 目录**，再替换程序文件；`data` 目录保留不动
2. 替换后首次启动，先核对已建连接与任务列表是否完整，再启动同步任务
3. 升级过程不会主动改动业务数据库；原有任务在您启动后按原配置运行
4. 之前用完全版的客户，升级后如连接的是 Oracle、达梦等数据库，请在「驱动管理」里补传一次驱动

端口调整、外部配置等高级用法见包内《使用说明》。旧版本仍保留在 [Releases](https://github.com/nmjugtzdw/lingqu/releases) 中，需要回退时可自行下载。

## 环境要求

- Windows 免安装包：Windows 10 / 11 / Server 2016 及以上 64 位，无需另装 Java
- 单独使用 jar 包：Java 17 或更高版本
- 建议 4 核 8 GB 以上内存；数据量大时按实际任务规模调整

## 实时同步的前提

默认的定时增量不读取源库日志。选用秒级实时同步时，源库需要开启相应日志并授予读取权限；MySQL 与 Oracle 之外的数据源按其自身能力使用逻辑复制或安全轮询。具体准备事项见包内《使用说明》。
