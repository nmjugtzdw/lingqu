# 灵渠 Lingqu

灵渠是给实施与运维人员用的数据库同步与迁移工具。它把「连接 → 结构迁移 → 全量装载 → 增量同步 → 校验修复 → 运行审计」整理成一条可复现的任务流程，支持完全离线的内网部署。

**当前正式版本：v1.0.1（2026 年 11 月）**

## 这版能感受到什么

- **任务多了搜索和筛选**：项目多的时候按名称找、按状态筛；没有匹配结果会明确提示，可以一键清除筛选，不用刷新页面重来
- **第一次用有引导**：首页直接列出上手要做的三件事 —— 建源连接、建目标连接、进向导体检并试跑
- **看板文案更清楚**：「已配置连接数」不会再被看成连接是否正常
- **改配置有提醒**：设置页补充了外部配置的加载方式，以及改配置前先暂停任务、备份数据的注意事项
- **沿用 v1.0.0 的全部能力**：打开就是中文、手机浏览器可看、建任务一步一页随时存草稿、跑完能导出报告、Windows 免安装包解压双击就能用

## 能做什么

- **连得上各类数据库**：MySQL、MariaDB、PostgreSQL、Oracle、SQL Server、达梦、人大金仓、OceanBase 等，也支持自行添加 JDBC 驱动
- **结构和数据一起搬**：表结构、索引、全量数据一次完成
- **增量同步**：定时增量，或基于数据库日志的秒级实时同步
- **跑得久也稳**：断点续传、并行分片、任务调度、失败重试、重启后接着跑
- **数据对得上**：抽查、差异诊断、表级重跑、切换追赶、运行审计
- **实施工具齐**：ETL、字段映射、批量规划、驱动管理
- **本地化部署**：配置与记录都存在本机，凭据加密、账号权限、日志轮转，不依赖外网

日常使用只需要首页、新建任务、同步任务、连接和设置；ETL、校验、日志等专业能力收在「高级能力」里。

## 下载与安装

1. 到 [Releases](https://github.com/nmjugtzdw/lingqu/releases) 下载 **v1.0.1**
2. 精简版下载 `lingqu-1.0.1-lite-windows-x64.zip`，解压后双击 `start.bat`
3. 浏览器打开 <http://127.0.0.1:27402>
4. 首次启动的管理员密码在 `data/initial-password.txt`，登录后请立即修改

已有 Java 17 的电脑，也可以只下载 `lingqu-1.0.1-lite.jar` 用 Java 命令启动，具体命令见包内《使用说明》。
需要 Oracle、达梦、金仓等数据库的驱动、不想自己放一次，可下载完全版 `lingqu-1.0.1-full-windows-x64.zip` 或 `lingqu-1.0.1-full.jar`。
四个文件的 SHA-256 校验值见同页的 `SHA256SUMS-v1.0.1.txt`；官网也提供同样的四个文件。

### 从旧版本升级

1. 先停止旧程序，**完整备份 `data` 目录**，再替换程序文件；`data` 目录保留不动
2. 替换后首次启动，先核对已建连接与任务列表是否完整，再启动同步任务
3. 升级过程不会主动改动业务数据库；原有任务在您启动后按原配置运行

端口调整、外部配置等高级用法见包内《使用说明》。

## 环境要求

- Windows 免安装包：Windows 10 / 11 / Server 2016 及以上 64 位，无需另装 Java
- 单独使用 jar 包：Java 17 或更高版本
- 建议 4 核 8 GB 以上内存；数据量大时按实际任务规模调整

## 实时同步的前提

默认的定时增量不读取源库日志。选用秒级实时同步时，源库需要开启相应日志并授予读取权限；MySQL 与 Oracle 之外的数据源按其自身能力使用逻辑复制或安全轮询。具体准备事项见包内《使用说明》。
